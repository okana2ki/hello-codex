Codex演習：測定データ解析

このフォルダは、8月19日のAI講習で使用する演習用データです。

measurement.csv は、ある小型回転機器を約15分間運転したときの
架空の測定データです。

主な列
- time_s              : 測定開始からの時間 [s]
- temperature_C       : 温度 [deg C]
- motor_current_A     : モータ電流 [A]
- rotation_rpm        : 回転数 [rpm]
- vibration_g         : 振動加速度 [g]
- supply_voltage_V    : 電源電圧 [V]

注意
- これは講習用に人工的に生成した架空データです。
- 実在する装置・会社・製品のデータではありません。
- データの中には、分析すると気づける変化や問題を意図的に含めています。
- 最初から「正解」を探すのではなく、Codexに何をどう依頼すると
  技術者として役立つ分析になるかを試してください。
