# hello-codex
- ChatGPT Codexの初心者向けハンズオンです。Codexの使い始めの敷居を低くすることを目指します。
- [演習内容の解説ページ](https://sites.google.com/view/genai4e/%E3%82%A4%E3%83%99%E3%83%B3%E3%83%88/codex)です。

## 構成
「事前準備」は各演習共通の事前準備です。Codexが初めての方はここから始めて下さい。「演習1,2,...」については、この順番にやる必要はありません。興味のある演習を選んで始めて下さい。
- [事前準備](https://drive.google.com/file/d/1UeHS6dRLWI2a7hhjnjcefxpwWgX2qK7D/view?usp=sharing)：ChatGPTデスクトップアプリのインストール → Codex権限の設定
- 演習1：機械装置の測定データ（架空のデータ）の分析
- 演習2：日常的な作業の例として、複数の関係者による会議の準備
